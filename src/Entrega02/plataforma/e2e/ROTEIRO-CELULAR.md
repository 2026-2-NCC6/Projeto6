# Roteiro no celular

Estes passos são para uma pessoa executar. Este arquivo não registra que já foram feitos.

1. No site publicado, o autor publica um treino curto.
2. No celular, em Configurações, entra `praticante@nockhug.local` e toca em Sincronizar agora, fora do Wi-Fi da lançadora.
3. O treino aparece em "Da plataforma".
4. A sessão usa a lançadora simulada, termina, e o histórico mostra "neste aparelho" se o aparelho estiver sem rede, ou "na nuvem" se o POST tiver ido.
5. Com rede, Sincronizar agora muda a linha para "na nuvem".
6. O site do autor mostra essa sessão uma vez só.
7. Repetir o passo 4 no Wi-Fi `Quadra-Local` não é exigência deste roteiro. A expectativa é: a sessão grava no aparelho e sobe quando o celular volta para uma rede com internet.
